# Nora Fleet Certification

To get your Nora Fleet certification, you need to pass a quiz. This document
outlines the steps for quiz preparation.

1. Visit the Nora Fleet repository on [GitHub](https://github.com/nvsinha/nora-studio)

2. Work through the [Tutorial](https://github.com/nvsinha/nora-studio/blob/main/docs/tutorial.md),
which walks from a first agent network to a working multi-agent system.

3. Read the Nora Fleet [User guide](https://github.com/nvsinha/nora-studio/blob/main/docs/user_guide.md)
